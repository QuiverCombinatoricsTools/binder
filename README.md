This repository is a *Binder repository* for *QuiverCombinatoricsTools*, which gives several online examples. This repository hosts the binder only, see [here](https://github.com/QuiverCombinatoricsTools/QuiverCombinatoricsTools) for the package itself.

We were supervised by [Gwyn Bellamy](https://sites.google.com/view/gwynbellamy/home) (University of Glasgow), as part of an [AGQ](https://www.agq-cdt.org/) computing project. The project is licensed under the *MIT license*. We are open to improvements and suggestions.

# Instructions

To run this binder, go [here](https://mybinder.org/v2/gh/QuiverCombinatoricsTools/binder/HEAD).
